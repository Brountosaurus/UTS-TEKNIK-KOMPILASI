## Deskripsi
Implementasi mini compiler dengan dukungan:
- Lexical Analysis (tokenizer)
- Parser dengan EBNF
- Abstract Syntax Tree (AST)
- Three Address Code (TAC) generation

## Fitur Tambahan
✅ Operator pangkat (`^`) dengan prioritas tertinggi

## Hierarki Operator
1. `^` (pangkat) - right-associative
2. `*` dan `/` (perkalian/pembagian)
3. `+` dan `-` (penjumlahan/pengurangan)
